# Agent Note: 模型选择保留提供方能力

Status: implemented

[English](2026-09-01-model-selection-capability.md) | 中文

## 问题

## 决策

模型选择器会在配置路由是已知提供方别名时，先通过 `ownedBy` 保留 pi-ai 推理元数据，再应用路由覆盖。路由及其上游提供方都没有确切目录条目时，`llm-dsh-ai` 提供共享强度列表，并把选择的等级安装到实际派发模型中。模型目录解析器会在派发前提供精确等级，因此旧会话保存的等级会在供应商 I/O 前被拒绝。用户可见诊断统一使用 `dsh-ai` 名称，pi-ai 依赖名仅保留在内部。

选择器菜单使用有上限的响应式宽度，并在模型列表内部隐藏横向溢出。过长的提供方或模型 id 会省略显示，不再产生第二条滚动条。

## Alternatives considered

**仅由提供方声明：**不采用，因为未本地配置的模型应以已安装目录元数据为准，而提供方默认值可能过时。

**只在界面过滤：**不采用，因为派发层也必须在网络请求前拒绝继承的无效等级。

## Consequences

覆盖范围包括已知及未列出模型的目录与适配器解析、界面推理强度选择，以及现有的客户端选择器重点测试。这些源码变更完成后仍需重新构建桌面壳，已安装 App 才会包含更新后的客户端 bundle。

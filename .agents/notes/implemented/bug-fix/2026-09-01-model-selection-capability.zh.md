# 模型选择保留提供方能力

[English](2026-09-01-model-selection-capability.md) | 中文

模型选择器现在会在配置路由是已知提供方别名时，先通过 `ownedBy` 保留 pi-ai 的推理元数据，再应用路由覆盖。路由及其上游提供方都没有确切目录条目时，`llm-pi-ai` 提供共享的 `off`、`low`、`high`、`max` 强度列表，并把选择的等级安装到实际派发模型中。这样私有网关和新增模型 id 仍可使用模型选择，同时已有目录模型继续使用精确等级。

选择器菜单使用有上限的响应式宽度，并在模型列表内部隐藏横向溢出。过长的提供方或模型 id 会省略显示，不再产生第二条滚动条。

覆盖范围包括已知及未列出模型的目录与适配器解析、界面推理强度选择，以及现有的客户端选择器重点测试。这些源码变更完成后仍需重新构建桌面壳，已安装 App 才会包含更新后的客户端 bundle。

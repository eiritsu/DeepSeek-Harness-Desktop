# Agent Note：Web 搜索提供方可观测性

状态：已实现

[English](2026-09-14-web-search-provider-observability.md) | 中文

## 问题

提供方无关的 `web_search` 工具会公开所选后端的答案与来源，却不公开其身份。桌面用户配置 Tavily 后，通用工具可能返回 Tavily 的 URL，但会话记录和结果卡没有证据说明请求由 Tavily 提供。由于专用 `tavily_search` 工具同时保持可见，模型还可能错误地把该调用描述为原生搜索。

## 决策

Web 服务在提供方执行后，把实际选中的搜索提供方 id 添加到每个规范化 `WebSearchResult`。该值由服务拥有，会覆盖提供方自行返回的同名字段，因此准确记录实时覆盖项、静态配置或唯一提供方解析策略所选择的提供方。

`dsh-tool-web` 把该 id 投影到模型可见输出、结构化呈现 metadata 和结果卡标题。多查询结果在合并来源时保留提供方 id。已有提供方实现仍保持源码兼容，因为它们直接返回的值中该字段可选；经 `ctx.web.search()` 返回的结果始终包含该字段。

## 考虑过的替代方案

**根据来源 URL 推断提供方。** 未采用，因为结果可以包含与 API 厂商无关的第三方域名，并且多个提供方可以返回同一个 URL。

**通用搜索选择某个提供方时隐藏对应的专用工具。** 未采用，因为专用工具可以公开提供方特有行为，其注册由另一项 external-tools 设置独立控制；隐藏工具也无法让历史通用调用变得可观测。

**只在桌面诊断中记录提供方。** 未采用，因为歧义存在于可移植工具结果、回放和所有客户端呈现中，并非只属于某个桌面壳。

## 结果

模型和用户可以核实通用搜索实际通过 `tavily`、`brave-search`、`exa` 或其他注册 id 执行。工具输出 schema 与录制快照包含新的可选字段；缺少该字段的旧持久化呈现 metadata 仍按原有标题渲染。已发布的多 Session fixture 保留其录制代际，并通过子 Session 提示词 sidecar 校验当前重建出的提示词。

聚焦的 Web 服务与工具测试固定提供方归属、渲染输出、metadata 解析和向后兼容行为。

# Agent Note：推理控制遵循供应商能力元数据

状态：已实现

[English](2026-09-01-reasoning-capability-and-empty-row.md) | 中文

## 问题

模型选择器曾为没有供应商推理能力元数据的模型显示 Off/Low/High/Max。适配器随后在分发时临时提升这些模型，因此控制项可以被选中，却没有供应商保证，也没有可靠的线协议效果。供应商还可能在输出文本前或关闭推理时发出空推理块，界面因此留下空白的“思考”行。

## 决策

只有目录或配置文件声明的推理能力可以被选择。对没有该能力的模型显式指定等级，会在供应商 I/O 前拒绝。空推理块不再渲染为助手思考折叠行。

## 测试

pi-ai 目录和适配器测试确认未声明模型不提供推理控制，同时确认已声明等级仍可选择。聊天覆盖测试确认空推理块不会渲染折叠行。

## 结果

未列入目录的模型必须在供应商配置中声明 `reasoningEfforts`，界面才会提供有效的推理等级选择器。目录模型继续显示其适配器实际支持的等级。
